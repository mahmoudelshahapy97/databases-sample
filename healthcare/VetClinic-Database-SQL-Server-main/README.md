\# VetClinic Database Management System



A comprehensive \*\*SQL Server\*\* database for managing a veterinary clinic, designed with \*\*normalized schemas\*\*, \*\*relational integrity\*\*, and \*\*business rules\*\* for core operations and financial tracking.



\---



\## Features



\- \*\*Core Schema\*\* – Customers, Animals, Staff, Visits, Examinations, Vaccinations.

\- \*\*Finance Schema\*\* – Invoices, Medications, Inventory, Service \& Medication invoice details.

\- \*\*Business Rules\*\* – Check constraints, foreign keys, and data integrity.

\- \*\*Sample Data\*\* – Pre-populated with realistic clinic records.

\- \*\*CRUD Operations\*\* – INSERT, UPDATE, DELETE with safe practices.

\- \*\*Queries\*\* – Sample queries for reporting and analysis.



\---



\## Technologies Used



\- \*\*Microsoft SQL Server\*\* (T-SQL)

\- \*\*Database Design\*\* (Schemas, Tables, Constraints)

\- \*\*Data Integrity\*\* (Primary/Foreign Keys, CHECK Constraints)

\- \*\*Normalization\*\* (3NF)
